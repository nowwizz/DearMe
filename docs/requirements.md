# 요구사항 정의서

**Dear. Me**는 나에게 보내는 크리스마스 초대장을 만들고 보관하는 서비스입니다. 방문 후보와 이용 정보는 한국관광공사 TourAPI, 구간 보행 경로는 TMAP, 겨울 준비 가이드는 Open-Meteo의 과거 자료를 사용합니다. 종료·보행 제한, 문화시설 이용 조건, 추위와 야외 이동 부담처럼 데이터로 판단할 요청이 대상입니다. 보관 결과는 날짜·시간·방문 순서·편지와 근거가 담긴 초대장입니다.

| ID | 필수 구현 | 검증 |
| --- | --- | --- |
| F3001 | 네 외부 Tool 등록, 설명, 입출력 스키마, 공통 성공·실패 | 등록부 API, 시연 입출력 |
| F3002 | TourAPI 지역·키워드·위치 기반 후보 검색, 기준일 안내 | 시연 후보 확인, 실제 인증 대기 |
| F3003 | 후보 ID와 유형으로 공통·소개 상세 요청 | 시연 ID 연결, 실제 속성 확인 대기 |
| F3004 | TMAP 거리·시간·경로와 Open-Meteo 날씨 정보 | Open-Meteo 실호출, TMAP 인증 대기 |
| F3005 | 대화의 기준·선호·제약 추출, 기준이 빠지면 질문 | 규칙 추출과 되묻기 확인, LLM 인증 대기 |
| F3006 | 실행 가능한 Tool과 앞뒤 의존성의 작업 순서 | 시연 작업 계획 이벤트 확인, LLM 선택 인증 대기 |
| F3007 | 후보 ID·좌표 연결, 실패를 포함한 통합 | 시연 이벤트 및 날씨 실패 삽입 확인 |
| F3008 | 보행·시간·이용·비용 조건 판단, 미확인 속성 보류 | 시연 보행 합·예산 보류 확인 |
| F3009 | 대안 순서 및 후보 조회, 기존 결과 재사용, 상한 | 시연 재계획과 3회 상한 확인 |
| F3010 | SQLite 세션 기억과 조건 부분 변경 | 시연 동행·보행 변경 확인 |
| F3011 | 편지, 지도·타임라인, 근거·제외 사유, 음악 | 시연 상세·로그 확인 |
| F3012 | 단계·Tool 호출·소요 시간·판단 이벤트 | 시연 전체 이벤트 확인 |
| F3013 | 독립된 로깅 Agent가 SQLite에 저장 | 미연결·저장 실패에도 응답 확인 |
| F3014 | 세션별 로그 목록·상세·삭제 | 브라우저/API 확인. 수정은 HTTP 405 |
| F3015 | 초대장 저장·목록·상세 및 시간 중복 안내 | 브라우저/API 확인 |
| F3016 | 날짜·시각·장소 수정과 삭제, 재검증 표시 | 브라우저/API 확인 |
| F3017 | FastAPI와 Pydantic 요청·응답 | OpenAPI 및 브라우저 확인 |
| F3018 | Vue 3 대화, 보관함, 실행 기록에 API 연동 | Edge 데스크톱·모바일 확인 |
| F3019 | 순서가 있는 이력, 재계획, 로딩, 실패 안내 | Edge 시연·인증값 미설정 상태 확인 |

| ID | 비기능 구현과 확인 |
| --- | --- |

| NF3005 | 시연 대표 요청 시간 기록. 실연동 처리 시간 확인 대기 |
| NF3006 | backend와 frontend 구분, Agent·Tool·이벤트·저장 코드 모듈 분리 |
| NF3007 | 공식 API 이용 조건 확인, TMAP 파생값 무기한 저장 방지, Open-Meteo 출처 표시 |
