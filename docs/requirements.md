# 요구사항 정의서

**Dear. Me**는 지하철역 주변 크리스마스 도보 코스를 만들고 편지 형태의 초대장으로 저장하는 서비스입니다. TourAPI에서 후보와 운영 정보를 얻고, TMAP에서 역 좌표와 구간별 보행 경로를 확보합니다. Open-Meteo의 과거 체감·강수·풍속은 겨울 준비 가이드에 사용합니다. 저장 결과는 날짜, 시간, 방문 순서, 편지, 검증 근거를 담은 초대장입니다. [기획 검증](domain-verification.md)

| 대표 요청 | 제약과 필요한 증거 |
| --- | --- |
| 강남역 근처에서 17:30–21:30 양식 저녁과 카페 | 역 반경 1.2km, 저녁 시간대, 공개 운영 정보, 각 구간 도보 최대 30분을 확인 |
| 종로3가역 근처에서 전시와 카페, 도보 10분 이내 | 후보 ID로 문화시설의 이용 정보를 확인하고, TMAP 이동 시간을 합산해 대안 순서를 평가 |
| 추위에 민감해 실내 위주로 방문 | 장소 분류와 과거 체감·강수 데이터를 조합해 실내 우선순위와 준비물 안내 |
